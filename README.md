File Integrity Monitor desarrollado en Python

Tecnologías:
    hashlib
    son
    os
    datetime
    argparse

Funcionalidades:
- SHA-256
- Detección de modificaciones
- Detección de nuevos archivos
- Detección de eliminaciones
- Logging
- Manejo de errores

Cómo ejecutar (En bash):
1era forma ---- python proyecto.py archivos 
2nda forma ---- python proyecto.py "C:\Users\User\Desktop\Documentos"
y para ver ayuda python proyecto.py --help
